Connect your device

Your device can reach OpenProxy. For HTTPS inspection, install this instance's public certificate.

Download CA certificate (DER) · Download PEM

iPhone / iPad

  1. Set the Wi-Fi HTTP proxy to Manual. Enter your Linux computer's LAN address and proxy port (default 8080).
  2. Open http://openproxy.local/ in Safari.
  3. Download the certificate above.
  4. Install the downloaded profile in Settings → General → VPN & Device Management.
  5. Enable full trust in Settings → General → About → Certificate Trust Settings.
  6. Open your app.
  7. Find its requests in the OpenProxy inspector on your computer.

Android

  1. Set your Wi-Fi proxy to Manual.
  2. Enter your computer's LAN address and proxy port (default 8080).
  3. Download the CA certificate.
  4. Install it in Settings → Security → Encryption & credentials (names vary by device).
  5. For your own app, enable user CA trust only in a debug build with Android Network Security Configuration.

The README mobile guide gives the XML configuration.

When an app does not appear

The app can ignore the proxy, use UDP/QUIC, reject user certificates, or pin its server's certificate. Use the app's debug configuration. For hosts with certificate pinning, use OpenProxy's bypass list to keep encrypted connections.

Automatic configuration / SOCKS

For Wi-Fi Automatic proxy settings, use http://COMPUTER_LAN_IP:8080/proxy.pac. For SOCKS, start a LAN SOCKS listener, for example --socks 0.0.0.0:1080. Use http://COMPUTER_LAN_IP:8080/socks.pac for its PAC URL. Replace 8080 with your HTTP setup port. Use the computer's LAN IP so the phone can retrieve the PAC file directly.

HTTP PAC file · SOCKS PAC file (with a SOCKS listener)

After use, remove the Wi-Fi proxy and debugging CA. Keep session files private. They can contain credentials and personal data.
